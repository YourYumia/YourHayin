# YourHayin
A test to determine your elemental alignment and polarity with HiSHiN's magic system Hayin.
## What is HiSHiN
HiSHiN is a shounen and shoujo inspired fantasy adventure project set in the fictional realm of Seyka. More specifically, HiSHiN is intended to feel adjacent to works like Genshin Impact and Avatar The Last Airbender.
